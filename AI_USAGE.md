# Использование генеративного ИИ

## Минимальная техническая основа API и sequencer

- Участник: `M1`.
- Задача: подготовить к EK1 запускаемый HTTP API и sequencer, который присваивает каждой принятой команде единый возрастающий номер; реализацию matching engine и WAL оставить за явно обозначенными границами текущего этапа.
- Использование ИИ: с помощью Codex подготовлены первоначальная структура C++-проекта, HTTP-адаптер на Crow, обработка Crow JSON, валидация команд, потокобезопасный sequencer, автотесты и инструкции запуска. Предложения ИИ требуют проверки и принятия ответственным участником.
- В проект вошло: исходный код API и sequencer в `include/` и `src/`, тесты в `tests/`, сборка в `CMakeLists.txt` и инструкция `docs/API.md`.
- Проверка человеком: прочитан и понят поток запроса от HTTP-адаптера через `CommandApi` к `CommandSequencer`; выполнена чистая сборка проекта по инструкции; запущены автотесты, включая конкурентную выдачу последовательности и отказ некорректной команде без расходования номера; вручную отправлены две корректные и одна некорректная HTTP-команда, проверены ответы и значение `last_sequence`; описание границы текущей реализации сверено с кодом.
- Связанный результат: `docs/API.md`, `src/api.cpp`, `src/sequencer.cpp`, `src/main.cpp`, `tests/sequencer_tests.cpp` и соответствующий коммит или pull request.
